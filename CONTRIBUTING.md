# Contributing to AskEU

Thank you for wanting to help. AskEU is in development, so the best way to contribute is to tell us what is wrong, unclear or missing.

## Where to write

| Topic | Where |
|---|---|
| A wrong, outdated or unclear rule or answer | Email hello@ask.eu.com with a link to the official source |
| How the AI is designed ([responsible-ai](https://github.com/askeucom/responsible-ai)) | Open an issue in that repository |
| The website ask.eu.com ([ask-website](https://github.com/askeucom/ask-website)) | Open an issue in that repository |
| Logos and brand use ([brand-assets](https://github.com/askeucom/brand-assets)) | Email hello@ask.eu.com |
| Partnerships, funding or press | Email hello@ask.eu.com |

## Issues

- Search first, so the same point is not raised twice.
- One topic per issue, with a short clear title.
- Link to an official source when you mention a rule.
- Never include real personal or medical data. See the [code of conduct](CODE_OF_CONDUCT.md).
- Security problems never go into issues. See the [security policy](SECURITY.md).

## Pull requests

Small pull requests are welcome, for example a typo, a broken link or a clearer sentence. For bigger changes, open an issue first so we can agree on the approach.

Please note that the website and the brand files are not open source (all rights reserved). By sending a pull request you agree that we may use your change in the project.
